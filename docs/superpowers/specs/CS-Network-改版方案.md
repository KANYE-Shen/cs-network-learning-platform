# CS Network 学习体验改版方案

日期：2026-10-23

## 目标与范围

优化现有 React/TypeScript/Vite 学习网站；覆盖现有 3 章、21 大节、41 细分小节、107 知识点。沿用课程组织、HashRouter、题库、收藏/错题/学习进度和 IndexedDB 数据结构。具体实施由 gpt-6-luna 子代理完成，主代理负责规划、审查与决策；子代理不得继续委派。

## 推荐方向

采用图解优先的学习工作台：纸白/暖灰底色、深墨色文字、蓝色重点、克制的绿色状态提示；同时完整适配深色主题。桌面保留清楚的章节导航与阅读区，手机目录折叠。减少嵌套卡片、重复标签和装饰图标，统一字号、留白、边线与焦点态。

备选方案：只调整配色和行距，工作量小但无法解决小节覆盖和阅读负担；完全重建课程与路由，改动大且增加用户记录兼容风险。本次选择在现有架构上改版。

## 页面阅读顺序

1. 标题、一句结论和学习状态。
2. 本小节 Anatomy 实验台：可播放/暂停/重置，提供可理解的阶段或参数，显示与模型一致的读数。
3. 当前知识点的必要学习语句：2–4 条经过人工编辑的关键要点，结论加粗、术语轻高亮；必要公式、变量、例题和易错条件必须可发现。
4. 可展开的完整讲解和推导；保留原有课程信息和来源追溯，去除界面上的重复展示。禁止用按字符或标点自动截断冒充精简内容。
5. 配套演示、练习、相关知识与前后节导航，避免同一演示重复挂载。

所有 107 个知识点都有简明阅读入口，而不是只改首页或少数样例。课程完整文本仍可展开访问，避免为满足简洁而丢失公式前提、协议例外、变量单位、题目解析和 PPT 来源。现有 AUTHORING 的内容完整性要求与此兼容。

## 图示覆盖与质量

以 outline 的 41 个 subsection 为最小覆盖单位，逐一建立可核验的映射。现有 21 图先逐图审查并改进，补齐缺失的 20 个细分小节。每个知识点页都能在本页直接看到所属小节的相关图示；共享小节图必须明确上下文，并针对不同知识点选择相关阶段/模式，不能把不相关的旧图无差别重复使用。

图采用 Anatomy 的 Figure 规格，每图一个清楚的机制，真实、精密的实体物件承载概念。先写概念到物件的映射、状态模型与部件清单，再写几何。基础/结构/机制/操控/主体分层，约 40–80 个有意义的部件。禁止换标题复用同一传送带，禁止只有方盒与箭头，禁止只为装饰而运动。概念模型、运动、读数、图注使用同一真相来源。

图内保留实体本身必要的刻度与显示，中文解释、图例、阶段说明放在卡片边缘。图示在 390px 宽度仍可读；播放按钮可键盘操作，遵循 reduced-motion，离屏与切后台停止无用动画。静态几何复用，避免每帧重建整个 SVG。保留 FigureCard 与 Scene 接口，不能修改 src/components/iso 工具包。

## 验收

- 覆盖清单证明 41/41 细分小节有相关图，107/107 知识点有简明阅读入口和可达图示；ID 引用有效且无悬空注册。
- 逐图核验实体映射、协议逻辑和读数；对使用 pipes/cables/round parts 的新图执行真实 Anatomy 几何审计。不得将自写引用检查称为几何审计，不得绕过失败。
- 桌面和 390px、浅色和深色、播放/暂停/重置、关键运动阶段、键盘与 reduced-motion 浏览器检查；保存并实际查看截图。
- npm run typecheck、npm test、npm run build 必须通过；node scripts/scan-ppt.mjs --check 若因未随仓库公开的 PPT 缺失而受限，需准确报告，不虚构通过。
- 保持全部既有知识点/题目/演示 ID、HashRouter 及 IndexedDB 结构兼容，检查进度、收藏、错题、搜索和备份功能。
- 更新真实覆盖报告与 README 数据；不提交版权 PPT、依赖目录、截图缓存或凭据。
